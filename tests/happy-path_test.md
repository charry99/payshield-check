# Happy path — a known-good link shows a Safe verdict

1. Open the app at the start URL.
2. Verify the page shows the heading "PayShield Check" and a link input field.
3. Paste `https://pancakeswap.finance/` into the link input.
4. Click the "Check link" button.
5. Wait for the verdict card to appear.
6. Verify the verdict badge reads "Safe".
7. Verify the reasons list is shown and includes a reason about HTTPS.
8. Verify the facts panel shows the host `pancakeswap.finance`.
