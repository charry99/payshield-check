# Suspicious link — a lookalike airdrop link shows Unsafe with reasons

1. Open the app at the start URL.
2. Paste `https://pancakeswap-airdrop-claim.xyz/` into the link input.
3. Click the "Check link" button.
4. Wait for the verdict card to appear.
5. Verify the verdict badge reads "Unsafe".
6. Verify the reasons list mentions the brand name "PancakeSwap" as a lookalike.
7. Verify the reasons list mentions the word "airdrop".
